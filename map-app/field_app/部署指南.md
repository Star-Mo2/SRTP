# 深田点位小程序 · 部署指南（PythonAnywhere）

本应用是一个独立的 Flask 小程序（地图点位 + 照片上传 + 现场记录）。
当前在本地 `127.0.0.1:5001` 运行，下面把它部署到公网服务器，让多人/跨设备共用。

> 目标服务器：PythonAnywhere（免费版即可跑 Flask + SQLite + 本地文件照片）。
> 你的账号：`StarMo`，站点后缀 `.pythonanywhere.com`。

---

## 一、部署前：先确认两件事

1. **数据库与照片目前都在 `field_app/` 目录里**（`field.db` + `uploads/`）。你本地所有点位改动、照片、备注都在这两个地方。部署时**建议把这两个一起上传，数据就带过去了**。
2. **存储后端目前是 `local`**（本地 uploads + 本地 SQLite）。部署后默认仍用 `local`——只要在服务器上创建 `field_app/uploads/` 目录并给权限即可。若以后要多人同时写并真正云端存储，再切到 OSS（见第五节）。

---

## 二、上传代码到 PythonAnywhere

用 PythonAnywhere 的 **Bash 控制台**，或直接通过 **Files** 页面上传。这里用命令行示例：

```bash
# 在 Bash 控制台里
mkdir -p /home/StarMo/field_app
# 把以下文件放进去（用 Files 页面上传，或 git clone）：
#   app.py  storage.py  wsgi.py  requirements.txt
#   templates/index.html
#   points.json                # 243 个识别点位坐标
#   field.db                   # 备份还原：把本地 field.db 一并上传
#   uploads/                   # 备份还原：把本地 uploads 目录一并上传（里面是现场照片）
```

> 如果走 git：把 `field_app/` 推到 GitHub，然后在服务器 `git clone` 过来。

## 三、装依赖

```bash
cd /home/StarMo/field_app
pip3.11 install --user -r requirements.txt
```

免费版 PythonAnywhere 会给一个 Web App，可在 **Web 标签**里选择 Flask 模板；也可以手动配 WSGI。

---

## 四、配置 WSGI

登录 PythonAnywhere → **Web** 标签 → 你的 web app → **WSGI configuration file** 点进去，指向 `wsgi.py` 的内容（或把下面贴进去）：

```python
import sys, os
FIELD_APP_DIR = "/home/StarMo/field_app"
if FIELD_APP_DIR not in sys.path:
    sys.path.insert(0, FIELD_APP_DIR)
os.environ.setdefault("FIELD_DB", os.path.join(FIELD_APP_DIR, "field.db"))
from app import app as application
```

然后：
- **Static files** 里加一条：`URL /uploads` → 目录 `/home/StarMo/field_app/uploads`
- 点绿色 **Reload** 按钮。

访问 `https://starmo.pythonanywhere.com/` 即可。

---

## 五、存储后端切换（可选，云端共享）

当前 `storage.py` 已把"照片存哪"抽成接口。默认 `local`（本地 uploads）。
想真正云端共享（多人同时传照片、跨设备不丢），把照片和数据库放到对象存储/云数据库：

- 在 `storage.py` 的 `create_photo_store` 里实现 `OssPhotoStore`（腾讯云 COS / 阿里云 OSS），
  只需实现 `save / get_url / delete` 三个方法。
- 设置环境变量 `PHOTO_STORAGE=oss`（当前未接入则回退 local，不会崩）。
- 数据库可换成 PostgreSQL/云 MySQL，通过 `FIELD_DB` 不再适用，改为在 `get_db()` 里接云连接。

**这一步先不急** —— 本地 `local` 后 + 服务器部署已经能让别人访问；
只有当遇到"多人同时写、照片量大、要跨设备永存"时再切云端。

---

## 六、PythonAnywhere 免费版坑

- 免费版 Web App **每 3 个月自动停用一次**（网址 404，不是代码问题）。
  恢复：登录 → Web 标签 → 点「Run until 3 months from today」→ 点绿色 Reload。
- 别动 `requirements.txt` 里不必要的包；免费版空间有限。

---

## 七、回到本地

本地仍可 `run.bat` 或 `python app.py` 直接跑（端口 5001）。
部署后你本地代码和服务器代码要保持一致；改了功能后，把改动的文件重新上传 + Reload 即可。
